# Contribute to Loop

Keep the backend in C and the frontend in TypeScript.
Preserve mobile layout, tap-start voice, full duplex, and WebTransport-only transport.
Use the existing Anvil contracts for admission, execution, experiments, review, and promotion.
Do not introduce another execution controller.

Run the [source checks](INSTALL.md#native-source-checks) before submitting a change.
Add focused tests for changed authentication, ownership, capture, or protocol behavior.
Keep recordings, prompts, private logs, credentials, and model weights out of contributions.
Use synthetic fixtures that contain no personal data.
Report measured results and their scope.
Do not describe synthetic checks as human acceptance.

Preserve source notices and record new dependency licenses and locked hashes.
Use signed commits where the receiving repository requires them.
Follow protected review and fast-forward merge rules.
Do not force-push protected branches or bypass checks.
